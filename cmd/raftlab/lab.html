    On the wire

      what these words mean
      term
      A numbered period with at most one leader. It only ever goes up. When a server sees a bigger term than its own it steps down immediately — this is how the cluster settles arguments without a central referee.
      follower / candidate / leader
      Followers do as they're told. A follower that stops hearing from a leader becomes a candidate and asks for votes. A candidate with votes from a majority becomes the leader.
      log
      The ordered list of commands. Every server must end up with the same commands in the same order — that is the entire job.
      appended vs committed
      Appended means one server wrote it down. Committed means a majority have, which makes it permanent: no future leader can erase it. Appended entries can still vanish.
      applied
      A committed entry that has actually been run against the key-value store. Commit decides the order; apply performs it.
      majority / quorum
      More than half. Of 5 servers, 3. Two majorities always share at least one member, which is why two leaders can't both be elected in one term.
      index
      An entry's position in the log, counting from 1. The columns in the log grid.
      no-op
      An empty entry a new leader appends immediately. Committing it proves the leader's log is up to date, which it must know before it can safely answer a read.
      AppendEntries
      The leader's one message: here are new entries, and here is what I think you already have. It doubles as the heartbeat — an empty one just says "still here".
      joint consensus
      How membership changes safely. The cluster passes through a state where a decision needs a majority of both the old and new membership, so the two can never elect different leaders during the switch.
      partition
      The network splitting so some servers can't reach others. Nobody gets told; from the inside it is indistinguishable from everyone else having crashed.
